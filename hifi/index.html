How I worked

I use Figma more like a scratchpad than a design tool. For both versions, v1 and v2, I made rough wireframes there first. It's a fast way to ideate and iterate. Then I built the screens in code (HTML, CSS and JS) using the tokens from Bolto's brand kit, and captured the coded screens back into the Figma file. The prototype is the code.

I like starting on a blank canvas. When I look at an empty page, it pushes me to think about ideas without the pressure of a final design. To me a designer's job is solving product problems, and most of the brain power goes into brainstorming, not into pushing pixels. From what I've seen, fast teams are designing less in Figma now, and I lean the same way. So I brainstorm in Figma and build in code.

One suggestion, if it's useful. Bolto's brand kit is already in Figma. Turning it into an MCP server would let the team use the same design system in code and ship UI faster.
